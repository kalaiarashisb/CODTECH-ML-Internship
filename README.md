# 🚀 CODTECH ML Internship Projects

This repository contains all tasks completed during the **CODTECH Machine Learning Internship**.  
The projects demonstrate practical implementation of Machine Learning, Deep Learning, NLP, Computer Vision, and Recommendation System concepts using Python and popular ML libraries.

---

# 📂 Projects Included

## 🔹 Task 1 — Titanic Survival Prediction using Decision Tree

### 📌 Overview
Built a machine learning model to predict passenger survival on the Titanic dataset using a **Decision Tree Classifier**.

### 🔧 Concepts Used
- Data Preprocessing
- Missing Value Handling
- Label Encoding
- Decision Tree Classifier
- Model Evaluation
- Confusion Matrix

### 📊 Outcome
The model successfully predicted passenger survival based on:
- Gender
- Age
- Passenger Class

---

# 🔹 Task 2 — Sentiment Analysis using TF-IDF and Logistic Regression

### 📌 Overview
Performed sentiment analysis on customer reviews using **Natural Language Processing (NLP)** techniques.

### 🔧 Concepts Used
- Text Preprocessing
- Stopword Removal
- TF-IDF Vectorization
- Logistic Regression
- Confusion Matrix
- Sentiment Classification

### 📊 Outcome
The model classified customer reviews into:
- Positive Sentiment
- Negative Sentiment

# 🔹 Task 3 — Flower Image Classification using CNN

### 📌 Overview
Built a **Convolutional Neural Network (CNN)** for flower image classification using TensorFlow and Keras.

### 🔧 Concepts Used
- Deep Learning
- CNN Architecture
- Conv2D Layers
- MaxPooling
- Image Normalization
- Image Classification

### 📊 Outcome
The CNN model successfully classified flower images into multiple categories such as:
- Roses
- Tulips
- Sunflowers
- Daisies

# 🔹 Task 4 — Movie Recommendation System using Collaborative Filtering

### 📌 Overview

### 🔧 Concepts Used
- Recommendation Systems
- Collaborative Filtering
- User-Movie Matrix

- Data Analysis
